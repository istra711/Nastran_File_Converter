# Building the standalone Windows executable

The project ships a PyInstaller **Onedir** build.  Onedir is used instead of
one-file because one-file executables are frequently quarantined by antivirus
heuristics, and because one-file builds must self-extract on every start.

## Prerequisites

- Windows 10 or newer.
- Python 3.9+ (developed with CPython 3.11.5).
- PyInstaller:

  ```bat
  pip install pyinstaller
  ```

- Optional, for STEP export at runtime: a FreeCAD installation.  FreeCAD is
  **not** needed to build and is **not** bundled.

## Build

From the project root:

```bat
.\build_exe.ps1
```

The script runs PyInstaller with:

```
--noconfirm --clean --onedir --windowed
--name NastranConverter --paths <root>
NastranConverter.py
```

and then packs the result:

```
dist\NastranConverter\                  the onedir application folder
dist\NastranConverter\NastranConverter.exe
dist\NastranConverter-win64.zip         portable ZIP of the folder
```

The EXE is windowed (no console).  The folder must stay together: the EXE needs
the `_internal` directory next to it.  For distribution, ship the ZIP.

## What is inside

- The full `nastran2stl` package (parser, STL writer, solid helpers, STEP
  bridge, converter, viewer).
- The Tkinter runtime (Tk/Tcl) provided by PyInstaller's hooks.
- `NastranConverter.py` as the entry script.

## What is *not* inside

- **FreeCAD.**  STEP export calls the FreeCAD installation on the target
  machine.  This keeps the ZIP small and avoids redistributing FreeCAD.
- Any third-party Python package (there are none at runtime).

## Running the EXE

```bat
dist\NastranConverter\NastranConverter.exe
dist\NastranConverter\NastranConverter.exe model.bdf
```

A BDF path can also be dragged onto the EXE.  The input and default output
folder are prefilled.

## One-file build (optional)

If your local antivirus allows it:

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
    --name NastranConverter --paths . NastranConverter.py
```

The result is a single `dist\NastranConverter.exe`.  The first start is slower
because the archive is unpacked to a temporary folder.

## The spec file

`NastranConverter.spec` is generated by PyInstaller on every build and records
absolute local paths, so it is **not** committed (it is covered by `.gitignore`).
`--clean` removes `build/` and `dist/` for a clean rebuild.  If you need a
reproducible, customised build, copy the generated spec, review the paths, and
commit it under a different name.

## Entry points

| File | Purpose |
| --- | --- |
| `NastranConverter.py` | Converter GUI / EXE entry point |
| `NastranViewer.py` | Viewer-only entry point |
| `python -m nastran2stl` | CLI |
| `python -m nastran2stl.converter_gui` | GUI |
| `python -m nastran2stl.viewer` | Viewer |

`NastranConverter.py` and `NastranViewer.py` are tiny wrappers that call the
package `main()` functions, so they can also be run directly with Python.

## Releasing

1. Bump `version` in `pyproject.toml` and `__version__` in
   `nastran2stl/__init__.py`.
2. Update [docs/changelog.md](changelog.md).
3. Run `python -m pytest -q`.
4. Run `.\build_exe.ps1`.
5. Create a Git tag and a GitHub release, attaching
   `dist\NastranConverter-win64.zip` as the release asset.

The ZIP is intentionally not committed to git; it is published as a release
asset.
